# arizona-athletics-web-templates

Shared design system and starter templates for University of Arizona Athletics web
projects. The goal is a single, on-brand baseline so developers — and the LLMs writing
code for them — produce visually consistent work whether the target is React, Next.js,
Astro, plain HTML+Bootstrap, HTML+Tailwind, Node/Express, or a Drupal Quickstart subtheme.

**Status:** planning. See [`PLAN.md`](./PLAN.md) for the full proposal.

## What's here today

- [`PLAN.md`](./PLAN.md) — the plan. Nothing built yet.

## What's coming

- `packages/ua-tokens` — single source of truth (CSS / SCSS / TS / Tailwind preset)
- `templates/` — React (Vite+), React lib, Next.js, Astro, HTML+Bootstrap, HTML+Tailwind,
  Node/Express, Drupal Quickstart subtheme, Hugo, email
- `docs/` — colors, typography, components, dark mode, auth, LLM guide
